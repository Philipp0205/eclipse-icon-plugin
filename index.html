Per-Workspace Eclipse Icon

An Eclipse plug-in that gives each workspace a distinct window and taskbar icon, a short icon label, and a window title suffix.

Update site

In Eclipse, open Help → Install New Software… and add this location:

https://philipp0205.github.io/eclipse-icon-plugin/p2/

This page is not the update site. Use the /p2/ URL above; the page you are reading cannot be resolved by Eclipse as a p2 repository.
